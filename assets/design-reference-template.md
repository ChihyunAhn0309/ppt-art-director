# Design reference and tool ledger

Complete this compact ledger inside the slide plan or as a companion file. English labels may be localized to the user's requested language.

| Reference URL | Access date | What was actually inspected | Communication problem / useful principle | Planned adaptation / slide IDs | Rejected traits | Asset reuse and terms |
|---|---|---|---|---|---|---|

Record limitations precisely: “cover plus thumbnails” is different from “full-size body slides.” Do not mark an inaccessible page as visually reviewed.

For a selected template, also record: creator/detail page and download URL; file/version or hash when acquired; current terms and required attribution; representative native-object inspection; chosen route (edit this template or independently compose from principles); layout-to-Sxx mapping. Keep a short reason for choosing it over the other inspected candidates. A reference URL alone is not proof that its file was downloaded, editable or licensed for delivery.

| Visual need | Selected available tool | Why it fits | Output and editable source | Cost/license source | Fallback and limitation |
|---|---|---|---|---|---|

Keep the tool set small and coherent. Inspect exported artifacts in the actual presentation, including the English and Korean versions when both are requested.
