# 센서 이상 탐지 모델의 경량화 — 슬라이드 기획안 v01

## 발표 조건과 원샷 결정

- 연구실 세미나, 한국어, 총 5장(표지 포함), 5분. 16:9 발표용 PPTX.
- 사용자가 별도 확인을 생략했으므로 기획 후 제작·검증까지 진행한다.
- 모든 성능 수치는 사용자가 제공한 가상 값이다. 동일 장치·데이터라는 조건만 알려져 있다.
- 표본수, 분산, 데이터셋명, 아키텍처, 증류 학습 설정, 양자화 범위와 방식은 알려져 있지 않다.
- 데스크톱 PowerPoint를 목표 플레이어로 삼는다. 실제 재생 검증 가능 여부는 별도로 기록한다.

## 메시지와 디자인

가상 예시에서 INT8 모델은 baseline 대비 지연 55%, 모델 크기 75%를 줄이지만 F1은 0.014 낮다. 이 값만으로 통계적 유의성이나 배포 적합성을 판단할 수 없다.

공정 이해 → 원자료 → 정량적 교환관계 → 해석의 한계 순서로 진행한다. 청록을 주 강조색으로 사용하고 모든 본문·수치·공정도를 편집 가능한 객체로 제작한다.

- 배경 #F7FAF9, 본문 #173F40, 보조 본문 #456162, 강조 #007E80, 비교 #7D9192, 흰색 #FFFFFF.
- 글꼴 Malgun Gothic: Windows 설치 파일 확인. 제목 36pt, 표지 48pt, 주요 본문 21pt, 주석 14pt. 글꼴 임베딩은 주장하지 않는다.
- 기본 여백 64px, 좌측 정렬. 최소 구성의 표지, 가로 공정도, native table, native chart, 결론 텍스트로 리듬을 만든다.
- 직접 본 참고: [MIT AeroAstro Annotated Example 2](https://mitcommlab.mit.edu/aeroastro/wp-content/uploads/sites/11/2025/02/Slides-Annotated-Example-2-R.pdf), PDF 1·6·10쪽 픽셀. 6쪽은 공정도가 큰 면적을 차지하고 옆에 설명을 둔다. 10쪽은 비교 그래프에 하단 해석을 붙인다. 크고 명확한 시각 대상과 해석의 근접 배치만 적용했다. 사진, 로고, 그림, 템플릿은 재사용하지 않았다.

## S01 — 표지, 30초

제목: 센서 이상 탐지 모델의 경량화

정확한 내용: 지식 증류와 INT8 양자화의 성능 교환관계 / 연구실 세미나 · 5분 / 모든 성능 수치는 가상 예시입니다

주제와 가상 예시라는 성격을 먼저 고지한다. 여백을 둔 청록 배경의 큰 native text. 애니메이션 없음.

발표 노트: 실제 실험 결과가 아닌 주어진 가상 데이터를 활용하여 경량화 과정을 설명한다. 장치·데이터가 같다는 조건을 유지하고 수치를 비교한다.

## S02 — 경량화 과정, 90초

제목: 원본 모델, 지식 증류, INT8 양자화

정확한 내용: 원본 모델 / baseline / 기준 모델, 교사 역할. 지식 증류 / distilled / 교사 예측을 활용해 작은 학생 모델을 학습. INT8 양자화 / int8 / 학생 모델의 수치를 8비트 정수로 표현. 연결선 라벨: 예측 지식 전달, 수치 표현 변환. 하단: 개념도이며 모델 구조·학습 설정·양자화 범위는 미제공.

native shape 3개와 연결선, native text 설명. 사용자 요청의 편집 가능한 과정도에 해당한다.

발표 노트: 첫 클릭에서 증류 학생과 설명, 둘째 클릭에서 INT8 단계와 설명. 증류와 양자화는 각각 모델 학습과 수치 표현에 관한 개념이라는 점을 설명한다. 실제 세부 구현은 알 수 없다.

근거: [Hinton et al., 2015](https://arxiv.org/abs/1503.02531), [Jacob et al., 2017](https://arxiv.org/abs/1712.05877). 이 문헌의 결과 수치를 본 예시로 가져오지 않는다.

애니메이션: 원본과 주석 항상 표시. S02-stage-2 및 동반 연결선·라벨·설명은 click fade 0.35s, S02-stage-3도 다음 click fade 0.35s. 정적판에는 모든 객체 표시. 슬라이드 수를 늘리지 않는다.

## S03 — 원자료, 60초

제목: 동일 장치·데이터에서 비교한 가상 성능

native table 전체 내용:

| 모델 | 지연(ms), 낮을수록 좋음 | F1, 높을수록 좋음 | 모델 크기(MB), 낮을수록 좋음 |
|---|---:|---:|---:|
| baseline | 120 | 0.910 | 48 |
| distilled | 72 | 0.902 | 18 |
| int8 | 54 | 0.896 | 12 |

정확한 주석: 표본수·분산·실제 데이터셋명 미제공 / 통계적 유의성이나 신뢰구간을 계산할 수 없음.

발표 노트: 단일 요약값끼리의 비교이며 지연이 평균인지 중앙값인지도 주어지지 않았다. F1의 집계 방식, 데이터 분할, 장치 정보 등은 알 수 없다. 출처는 사용자 제공 가상 데이터. 애니메이션 없음.

## S04 — 교환관계, 65초

제목: 지연 55% 감소와 F1 0.014 하락

좌측 native bar chart: baseline 120ms, distilled 72ms, int8 54ms, 값 축 0에서 시작. 오른쪽: baseline 대비 INT8 / 모델 크기 75% 감소 / 48MB에서 12MB / F1 0.014 하락 / 0.910에서 0.896. 아래: 증류 단계: 지연 40% 감소, F1 0.008 하락 / 추가 INT8 단계: 지연 25% 감소, F1 0.006 하락.

발표 노트: 지연 감소율은 (120−54)/120=55%, 모델 크기는 (48−12)/48=75%. F1은 절대 차이이다. 25%는 72ms를 기준으로 한 추가 감소로 전체 감소율과 더하지 않는다. 애니메이션 없음.

## S05 — 해석의 한계, 55초

제목: 배포 판단에 필요한 추가 근거

정확한 내용: 이 가상 예시는 효율과 F1의 교환관계를 보여줍니다 / 먼저 정할 기준: 허용 가능한 F1 저하와 지연 한도 / 다음 검증: 반복 측정의 분산, 이상 유형별 실패 사례 / 현재의 한계: 표본수·실제 데이터셋명이 없어 일반화 판단 불가.

발표 노트: 어느 변형이 최선이라고 단정하지 않는다. 실제 운영에서 중요한 이상 유형과 지연 요구를 정한 뒤 평가가 필요하다. 모든 수치는 가상이며 실제 적용 결과를 예측하지 않는다. 애니메이션 없음.
